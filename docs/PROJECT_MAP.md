## 📖 Story text (what the player reads)

The narrative flows through 3 layers — **you edit Layer 1**, scripts push it down.

| Layer | Folder / file | What's in it |
|---|---|---|
| **1. Sources (edit these)** | [tools/reskin_narration.json](../tools/reskin_narration.json) | 42 chapter openers |
| | [tools/reskin_banter.json](../tools/reskin_banter.json) | pre-battle party banter, all 42 chapters |
| | [tools/reskin_post_battle.json](../tools/reskin_post_battle.json) | post-battle aftermath beats + join scenes |
| | [tools/build_reskin_xlsx.py](../tools/build_reskin_xlsx.py) | character names/bios, boss names, chapter titles, enemy naming rules (`CHARACTERS`, `BOSS`, `RESKIN_NAME`, `reskin_enemy`) |
| **2. Wire scripts** | [tools/](../tools) | `wire_reskin_into_game.py`, `wire_reskin_descriptions.py`, `wire_reskin_enemy_names.py`, `wire_chapter_joins.py` |
| **3. Generated (do not hand-edit)** | [text/autogenerated/](../text/autogenerated) | 95 files: `script_*.json` (narration), `dialogue_*.json` (banter), `*_post_battle.json` |
| | [text/text.csv](../text/text.csv) | chapter titles, captions, hero names, dialogue speaker labels |
| **4. Compiled (what the game loads)** | [text/text.en.translation](../text/text.en.translation) · [text/text.es.translation](../text/text.es.translation) | built from `text.csv` |

Character bios also live inline on each unit: `description` field in [jobs/terra/](../jobs/terra) `*_job.tres`.

## The reskin loop (change text → see it in game)

1. Edit a **Layer 1** source (`tools/reskin_*.json` or `build_reskin_xlsx.py`)
2. Run the wire script(s) in [tools/](../tools)
3. Rebuild translations: `godot --headless --path . --script res://tools/build_translations.gd`
4. Re-export: `godot --headless --export-release "Web" build/web/index.html`
